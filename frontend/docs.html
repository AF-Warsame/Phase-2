Quick Start

  1. API Base URL: https://7c1jore560.execute-api.us-east-1.amazonaws.com/prod
  2. Authenticate: click PUT /authenticate (default user/password are filled). Copy the returned bearer token.
  3. Paste the token into “Bearer Token (X-Authorization)”.
  4. Create an artifact: choose type model, set Source URL (e.g., https://huggingface.co/google-bert/bert-base-uncased), click POST /artifact/{type}.
  5. Use the returned id with GET, DELETE, /rate, /lineage, /license-check, /cost.

Endpoints Mapped

  • Health: GET /health, GET /health/components
  • Auth: PUT /authenticate (returns bearer token)
  • Create: POST /artifact/{type} (model|dataset|code)
  • List: POST /artifacts (optional regex search via /artifact/byRegEx)
  • Get/Delete: GET/DELETE /artifacts/{type}/{id}
  • Rate: GET /artifact/model/{id}/rate
  • Lineage: GET /artifact/model/{id}/lineage
  • License: POST /artifact/model/{id}/license-check
  • Cost: GET /artifact/{type}/{id}/cost

Troubleshooting

  • 401/403: Ensure the bearer token is set in the X-Authorization field.
  • 500: Try again after a few seconds; if persistent, re-auth and retry create.
  • Network errors: Serve the app via HTTP (e.g., python -m http.server 8000) instead of opening from file://

Hosting the UI

Serve the frontend/ folder via any static host:

  • AWS S3 + CloudFront: aws s3 sync frontend s3://your-bucket --delete, enable static website hosting, front with CloudFront.
  • GitHub Pages: Push frontend to a branch and enable Pages.
  • Simple server: python -m http.server 8000 and share the URL on your LAN/VPN.
